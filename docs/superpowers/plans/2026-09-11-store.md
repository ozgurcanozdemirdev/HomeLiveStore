# Home & Living Store Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development to implement the bounded lanes below.

**Goal:** Çalışan Türkçe mağaza, admin ve API ile sepet onayından sipariş oluşturan ders projesi.

**Architecture:** Mevcut .NET katmanları, SQLite ve MVC korunur. API controller'ları Web hostuna application part ile eklenir; bağımsız API hostu da çalışır.

**Tech Stack:** .NET 10, ASP.NET Core MVC, EF Core SQLite, vanilla JavaScript/CSS.

**Spec:** docs/superpowers/specs/2026-09-11-store-design.md
